# Project instructions

- After completing and verifying an update, commit and push it to `origin/main` (`https://github.com/jamesdoom/math.git`). The user authorized this standing workflow on October 12, 2026. Report the pushed commit and any remaining limitations.
- Preserve existing student progress and stable content IDs when updating curriculum.
- Run TypeScript checks, relevant tests, and the production build before pushing. Verify changed student flows in a browser when UI or learning interactions change.
- Keep dependencies, builds, temporary verification files, and private source PDFs out of commits. `.gitignore` excludes `node_modules`, `dist`, and `.verification`.
- Scope is Chapter 3 linear functions. Use supplied notes as the curriculum source, create original practice, and label any inferred material accurately.
