## Source coverage

The page states two objectives: find a line's slope and y-intercept, then use them to write its slope-intercept equation. Its three example types provide:

1. A given slope and y-intercept, including fractional intercepts and a zero slope.
2. Graphs with clear marked points, signed rise/run, and a visible y-axis crossing.
3. Tables of points with a row at x = 0; slope from coordinate differences; repeated decimal outputs simplifying to a horizontal-line equation.

The bottom of the scan contains a cropped practice area. Missing/cropped exercises are not guessed. All app problems are original variations of the fully visible example types; the worksheet is not reproduced.

## Five short lessons

| Lesson                         | Small decisions before the complete problem                                                                                               |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Find the two building blocks   | Identify the signed x-coefficient m; identify b; connect b with (0, b)                                                                    |
| Write an equation from m and b | Place m; place b; simplify −1x and signed constants; check x = 0                                                                          |
| Write an equation from a graph | Read b; find signed rise; divide by run for m; combine the values                                                                         |
| Write an equation from a table | Read the output at zero; calculate y-change and x-change separately in the same order; simplify their ratio; write and check the equation |
| When the slope is zero         | Notice constant outputs; find zero rise and zero slope; substitute into y = 0x + b; simplify to y = b                                     |

Every lesson has four short stages: one concept, a worked example revealed one move at a time, guided decisions, then three independent checks. Worked examples have previous/next controls and reveal the completed graph after the final move. Guided problems contain two to five answer steps. Six independent items per skill give 30 total, including prerequisite recognition and full equations. Independent skill rounds use three questions; mixed rounds use one per skill for five total. Practice links back to each relevant guided lesson.

The authored guided examples explicitly supply already established m and b at the assembly step, so the student does not have to remember several results while deciding where to place them. Hints, progressive simpler explanations, and targeted feedback address sign errors, swapping m/b, rise/run inversion, using only the output change, ignoring input spacing, and retaining x when its coefficient is zero. Full solutions remain available after progressive assistance. Assisted answers do not inflate independent mastery.

## Scope boundaries

- Use conventional `y = mx + b` with a signed b; the sheet's `± b` shorthand does not mean the student chooses a sign arbitrarily.
- Fractional slopes are shown with parentheses in plain-text equations; decimal intercepts remain decimals. Both are within the supplied examples.
- Tables used to find an equation include x = 0, as on the sheet. Finding b from two nonzero-input points, point-slope form, standard-form conversion, parallel/perpendicular lines, scatter plots, nonlinear recognition, domain/range exercises, and word problems are not part of this release.
- A horizontal line has slope 0 and equation y = b. Brief feedback distinguishes an incorrect x = b answer without adding vertical-line exercises as another topic.
- Negative inputs and simple arithmetic are used only as prerequisites for the page's tasks.
